ukrop

Quick Directory Jumping & Command Execution

A fast TUI for navigating directories, re-running commands, and connecting via SSH.

Built with Rust. Open source. MIT license.

Voice: "Every day we type long paths, dig through history, look up SSH aliases. ukrop puts all of that in one fast, fuzzy-searchable interface."

The Problem

$ cd ~/projects/api-server/src/handlers     # too much typing
$ history | grep docker                      # noisy, wrong match
$ cat ~/.ssh/config                          # scroll to find the alias

We do this dozens of times a day.

Shells give us cd, Ctrl+R, and ssh -- but they don't talk to each other.

Voice: "We all do this dozens of times a day. There's a faster way."

Install & Setup

$ brew install gupalo/tap/ukrop

$ ukrop setup
  • Imports shell history & SSH config
  • Adds shell integration to your rc file
  • Enables the u shortcut

Supports zsh, bash, fish, PowerShell

Frecency Scoring

Not just frequency. Not just recency. Both.

  • Exponential decay with 1-week half-life
  • 100 visits a month ago < 10 visits today
  • Automatic aging when total scores exceed threshold
  • Near-zero entries pruned automatically
score = old_score * 2^(-elapsed/week) + 1

# Yesterday's hot directory:   12.4
# Last week's project:          3.1
# Last month's experiment:      0.2  (auto-pruned)

The right items are always at the top -- without manual sorting.

Voice: "Frecency combines frequency and recency. A directory visited 100 times a month ago scores lower than one visited 10 times today. The most relevant items always float to the top automatically."
